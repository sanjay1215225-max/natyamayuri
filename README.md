# natyamayuri

Static site for natyamayuri.com — South Indian classical dance academy.

This repository contains a simple responsive static website (HTML/CSS/JS) and three SVG logo options.

How to view locally:
1. Clone the repo
2. Open index.html in a browser

Deployment:
- The site is ready for GitHub Pages. The URL will be: https://sanjay1215225-max.github.io/natyamayuri/ (may take a minute after push).

Replace the placeholder images in images/ with real photos and update contact details in index.html.
